🛡️ Multi-Tenant Row-Level Security (RLS)
Kernel-level PostgreSQL isolation preventing cross-tenant data leaks
Zero-Trust Security Model
Every database query and storage access is explicitly scoped to the user's authenticated tenant_id. Even if a developer forgets a WHERE tenant_id = ... clause in SQL, PostgreSQL RLS rejects unauthorized access at the database engine level.
🔑
JWT Claims
FastAPI validates Bearer JWT tokens. Each payload carries tenant_id, user_id, and role. Dual-token model: Access (15m) & Refresh (7d).
🗄️
8 RLS Protected Tables
tenants, users, folders, documents, document_versions, document_chunks, metadata_items, api_logs.
🔒 Storage Layer Isolation
S3 Keys are prefixed by tenant: s3://bucket/{tenant_id}/{document_id}/{filename}. Pre-signed URLs are only emitted after checking DB tenant ownership.

Waterfall Search Flow Blueprint
0
Redis Semantic Cache Lookup
Hashes query string + tenant ID. If hit, returns synthetic answer instantly.
1
PostgreSQL Hybrid + HyDE Fallback
Executes pgvector HNSW search + full-text tsquery + synthetic HyDE expansion.
2
Cohere Cross-Encoder Re-Ranking
Evaluates top 20 candidate chunks against user query intent; trims to top 3 best chunks.
3
Generative LLM RAG Synthesis
Generates final answer using strictly top 3 chunks with document title & page number citations.
🧠 AI Ingestion Engine & Hot-Swapping
Multi-format document processing with 0-code-change provider adaptability
Document Parsing Pipeline
Extracts raw text, table structures, and slide notes using specialized native parsers: pdfplumber (PDF), python-docx (Word), openpyxl (Excel), python-pptx (PowerPoint), and LlamaParse OCR (Scanned PDFs).
Ingestion Brain (Dynamic Metadata)
An LLM parses raw text into dynamic JSON metadata without fixed database schemas: extracts document_type, category, urgency, key_entities, and dates into PostgreSQL JSONB columns.
⚡ Thread-Safe Provider Singleton Caching
Provider instances are cached via get_ai_provider_factory(). Eliminates model setup overhead and memory leaks across async requests.

🔒 Defense-in-Depth AI Guardrails & Privacy
Intercepting adversarial prompt injections and redacting sensitive PII data
🛡️
Input Guardrails (Pre-Retrieval)
Interprets input queries before vector lookups or LLM calls.
• Jailbreak Pattern Detection: Scans for phrases like "ignore previous instructions" or "override system prompt".
• Immediate Abort: Returns took_ms: 0 with Safety Block response detail.
• Input PII Scrubbing: Redacts sensitive parameters before sending queries to external API endpoints.
🧹
Output Guardrails (Post-Synthesis)
Sanitizes generated RAG summaries before sending them to the client interface.
• Scans synthesized summaries using regular expression patterns.
• Automatically redacts confidential user data found in document snippets.
